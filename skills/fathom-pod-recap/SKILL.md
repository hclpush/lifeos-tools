# Fathom Pod Recap → Community Post

Fathom's post-meeting email is packed with per-line tracking hyperlinks (`utm_campaign=postmeetingsummary...`) that make it unusable to paste straight into a community post. This skill pulls the raw content, strips every inline link, and re-outlines it into a clean format — keeping only the recording link at the top.

## Setup

Set your Gmail address (the mailbox where Fathom recaps arrive) here before installing:

```
MAILBOX = <your-gmail-address>
```

Note: if recaps are *forwarded* into this mailbox from another address, search this mailbox, not the original recipient.

## Steps

### 1. Find the email
Search `$MAILBOX` (in order, first hit wins):
1. `subject:"Recap of your meeting with <company/domain>"` if the user names the counterparty
2. `Fathom` + `Recap of your meeting` if no counterparty given — pick the most recent match
3. Sender is always `Fathom <no-reply@fathom.video>`, but it may arrive as a **forward** (`Fwd: Recap of your meeting with ...`) rather than a direct inbound message — search threads, don't filter by sender alone.

### 2. Pull the body
`get_message` on the matched thread. The response is large — if it exceeds the tool's output limit, it will be saved to a file automatically. Extract `plaintextBody` from that file (not `htmlBody` — far less link noise to strip) rather than reading the raw JSON inline:

```bash
python3 -c "import json,sys; print(json.load(open(sys.argv[1]))['plaintextBody'])" <saved-file-path>
```

From the plaintext, capture:
- **Meeting title** and **counterparty** — from the `Meeting with <domain>` header line
- **Date + duration** — from the line under the title (`<Month DD, YYYY> • <NN> mins`)
- **Recording link** — the `View Meeting <https://fathom.video/share/...>` URL. Strip all `utm_*`/`tab=`/`timestamp=` query params, keep just `https://fathom.video/share/<id>`. This is the *only* link that survives into the final post.
- **Action Items** block (name + owner pairs)
- **Meeting Summary** block: Meeting Purpose, Key Takeaways, Topics (with subpoints), Next Steps

### 3. Strip every other link
Every bullet under Key Takeaways / Topics / Next Steps has a trailing `<https://fathom.video/share/...&timestamp=...>` link — delete these entirely, keep only the bullet text. Also drop all Fathom marketing boilerplate (header ad, G2 reviews badge, "Ask Fathom" footer, referral bonus line).

### 4. Re-outline into the fixed structure
Always these six sections, in this order — omit a section only if the source email has nothing for it:

1. **Attendees** — infer from action-item owners (unique names). If the email has an explicit attendee list, use that instead.
2. **Meeting Purpose** — verbatim from the source's "Meeting Purpose" line.
3. **Key Takeaways** — the source's "Key Takeaways" bullets, link-stripped.
4. **Progress & Challenges** — synthesized from the "Topics" section: what's working / validated (progress) vs. blockers or open problems (challenges). Don't just copy Topics verbatim — sort each point into progress or challenge.
5. **Learnings** — synthesized from any evaluative/reflective content (tool reviews, workflow lessons, conclusions) that isn't a raw action item.
6. **Others** — Action Items (name — owner) and Next Steps (grouped by owner), verbatim content, link-stripped.

Header block above the six sections:
```
**Meeting with <counterparty> — <meeting title>**
<Month DD, YYYY> • <NN> mins
```

Closing block, always exactly this (recording link goes here, not in the header):
```
Recording on Fathom: <clean fathom.video/share/... link>
Recording from Google Meet will be posted separately.

Note generated by Fathom. Manually reviewed by _____
```

### 5. Save the draft
Write to `400_Content/skool/drafts/<slug>-<YYYY-MM-DD>.md` in your vault (slug from the meeting title) — or the drafts folder of whatever platform your community lives on. If you use this repo's draft-frontmatter hook, it auto-adds `author/ai_assistant/date/status/platform` — don't add that frontmatter manually.

Don't paste the full draft into chat — confirm the file path and give a 2-3 line summary of what's in it.
